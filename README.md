# 🔬 How I Test

I follow a simple approach:

```text
        REQUIREMENT
             ↓
       TEST SCENARIO
             ↓
         TEST CASE
             ↓
      MANUAL EXECUTION
             ↓
       ┌─────┴─────┐
       ↓           ↓
     PASS         FAIL
                   ↓
              BUG REPORT
                   ↓
              FIX VERIFIED
                   ↓
            REGRESSION TEST
                   ↓
            AUTOMATION
```
